# Archive

This directory holds documents that have been replaced but may still be useful for reference.

## Rules

- Archive a document instead of deleting it when its history still explains a decision.
- Add a short header to the archived copy: the date it was archived, what replaced it, and why.
- Keep the original filename unless it would be ambiguous next to its replacement.
- Never archive the current source of truth. `AGENTS.md` and the active files under `docs/` are not archived while they remain in use.
- Link the replacement when one exists.

## Current state

No documents have been archived. The documentation set was established on 2026-11-10 and has not yet replaced an older tracked document.

Git-ignored working plans and specs under `docs/superpowers/` are not archived here. They are temporary planning artifacts and remain outside the published documentation set.
