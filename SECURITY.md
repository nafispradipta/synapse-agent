# Security Policy

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

We take the security of `synapse-agent` seriously. If you discover a vulnerability or security flaw, please do not disclose it publicly via issue trackers.

Instead, please send an email to:
**halo@nafispradipta.id**

Include the following details:
- A description of the issue and potential impact
- Steps to reproduce or a proof of concept
- Suggested mitigations or fixes (if available)

We will acknowledge your report within 48 hours and work with you to resolve the issue before public disclosure.
